# GeoDataAnalytics

The data side of geospatial analytics. This repo covers acquiring US Census,
IRS and Copernicus data, landing it in object storage as GeoParquet,
querying it in place with DuckDB, and testing geospatial LLM agents against it.
There is no database server: the lake on S3 is the system of record.

It's the public "behind the scenes" for the data that powers
[GeoAgent](https://geoagent.app). App, user and infrastructure code lives
elsewhere. Nothing here depends on it.

```mermaid
flowchart LR
    src[Census TIGER / ACS / Gazetteer / RUCA / LODES / IRS SOI] -->|scripts/| raw[(Wasabi<br/>origin/  raw files)]
    raw -->|scripts/tiger_to_lake.py<br/>scripts/get_reference_data.py<br/>warehouse/load ACS lake step| lake[(AWS S3 us-east-2<br/>curated/  GeoParquet)]
    lake <-->|lake_targets sync| arch[(Wasabi<br/>curated/  archive copy)]
    lake --> duck[DuckDB: notebooks, scripts, agents]
    lake --> tiles[PMTiles  GeoAgent tile build]
    lake --> llm[geo-llm-lab/evals  agent benchmark]
    lake --> sedona[spark-sedona-lab/]
```

## Where the data lives

| Location | Contents | Size |
|---|---|---|
| `s3://<bucket>/origin/` | Raw downloads: Census TIGER and surveys (ACS, decennial, PopEst, BRDS, economic census, gov finances, MHS), IRS SOI (county, ZIP, migration, congressional), Natural Earth | ~300 GiB, 210k files |
| `s3://<bucket>/curated/` | Boundary GeoParquet partitioned by `boundary_type/year`, with H3 + bbox keys; ACS 5-year; reference tables (Gazetteer, RUCA, ZCTA relationships, LODES). Identical copies on **AWS S3** (primary, serves GeoAgent) and **Wasabi** (archive). | see `warehouse/README.md` |

## Using the data from another repo or notebook

Read the Parquet straight from S3: `read_parquet('s3://<bucket>/curated/...')`
from DuckDB (with the `spatial` extension), GeoPandas (`gpd.read_parquet`),
Sedona or QGIS, with a read-only key for the AWS bucket (or the Wasabi archive).
Filter on `boundary_type`/`year` paths and the `h3_r5`/bbox columns before
touching geometry.
